# Szkolne sprawdziany

Aplikacja do nauki dla klasy 4: Historia, Przyroda, Angielski, Matematyka.
`index.html` to gotowa, samodzielna aplikacja (otwórz w przeglądarce).
`src/` – dane przedmiotów, `build.py` składa `index.html` (wymaga `historia.html` jako źródła silnika), `test2.js` – test generatorów zadań.
