# Szkolne sprawdziany

Aplikacja do nauki dla klasy 4: Historia, Przyroda, Angielski, Matematyka.
`index.html` to gotowa, samodzielna aplikacja (otwórz w przeglądarce).
`src/` – dane przedmiotów (matematyka to osobny moduł `src/math_app.html`, osadzony w ramce), `build.py` składa `index.html` (silnik z `src/historia-engine.html`; uruchom `python3 build.py`, test: `node test2.js`), `test2.js` – test generatorów zadań.
